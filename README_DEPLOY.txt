CAMSTUDY deployment

1. Upload the contents of this folder to the same Render web service.
2. Build command: npm install
3. Start command: npm start
4. Environment: OPENAI_API_KEY (for AI questions), TEACHER_PASSWORD (teacher login password).
5. Browser title remains CAMSTUDY.

Teacher login uses the TEACHER_PASSWORD environment variable. If you set TEACHER_PASSWORD to a value different from ADMIN123, use the new value. Never place API keys in the HTML file.
